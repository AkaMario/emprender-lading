## Límites reflejados en los textos

- Las capacidades de inventario, agenda y reportes varían según el modelo elegido.
- Los pagos y las renovaciones se registran manualmente; Emprender no confirma transferencias bancarias ni realiza cobros automáticos.
- Los datos y la comprobación de disponibilidad de reservas son locales; no se anuncia sincronización entre cajas o dispositivos.
- El respaldo no es automático ni incluye alojamiento en la nube.
- No se anuncian importación desde Excel, conexión a básculas, lectores, impresoras, KDS remoto ni control de permisos externos.
- Se eliminaron superlativos de velocidad y promesas de suscripciones o comisiones futuras. La descarga pública del APK se mantiene con la URL facilitada por el propietario.

Se revisó el código fuente local para corregir el contenido de la landing.
